# Publication Order vs Chronological Order: Terminal List, Powerless and Bridgerton

Reading order is not always one list. Some series have a publication order, a chronological order, and a handful of novellas that fit between the main books. Here is how three series on the Books in Order site handle the difference, and which list to follow first.

## The Terminal List: two lists that differ

Jack Carr's military thriller series has eight published books and a ninth dated October 5, 2027. The [Terminal List books in order](https://books.resuhive.com/series/terminal-list-books-in-order/) page shows a publication list and a chronological list, because one prequel-style entry, Cry Havoc (October 7, 2025), takes place earlier in the timeline than it was released. For a first read, the publication list is the safer path because it keeps each reveal where the author placed it.

## Powerless: novellas in the middle

Lauren Roberts' series is listed as five entries on the [Powerless books in order](https://books.resuhive.com/series/powerless-books-in-order/) page: Powerless, the Powerful novella, Reckless, Fearless and the Fearful novella. The novellas are short, and they are written for readers who have already finished the main book beside them. If you read in publication order you meet each novella at the right moment.

## Bridgerton: order barely matters, but it helps

Julia Quinn's ten Bridgerton books each follow one sibling, so you can start with any couple and follow the story. Even so, the [Bridgerton books in order](https://books.resuhive.com/series/bridgerton-books-in-order/) list starts with The Duke and I (January 5, 2000) because the later books refer back to events in the first few. The family is easier to track if you meet them in the order they were published.

## A quick way to choose

1. If a series lists novellas, read in publication order.
2. If a series has a chronological list, use it only for a re-read.
3. If every book follows a different couple, pick the couple you like and fill in the rest later.
4. If a next book is dated, check the date again before you pre-order.

The same approach works for any author.
